# air-traffic-simulator

A desktop **Java (AWT)** Air-Traffic simulator.  
Small, testable components with strict OOP design and clean architecture.

## Features

- **Map** — interactive `Canvas`
- **Drawable Models** — `Airports`, `Airplanes`, `Storms` and `Typhoons`
- **Airport and Flight Tables** — Editable Model tables on the sidebars
- **I/O** — CSV **Load/Save**: airports & flights (File menu)
- **Simulation** — discrete timer, pause/resume, scheduler & engine
- **Rendering** — **double buffering** to eliminate flicker
